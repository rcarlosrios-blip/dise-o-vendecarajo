Palabra corta (3–6 letras, minúsculas) con cada letra en un cuadro de color plano; para preguntas clave o conceptos-ancla.
```jsx
<LetterTiles word="qué" />
<LetterTiles word="cómo" colors={['ink','red']} size={160} />
```
- colors: ciclo de colores por letra (red, ink — alterna)
- Apila varias palabras en columna para listas tipo why/how/who
