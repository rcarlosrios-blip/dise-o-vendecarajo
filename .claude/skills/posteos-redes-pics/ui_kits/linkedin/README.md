# Kit LinkedIn — Roberto Ríos

Piezas de contenido para LinkedIn construidas con los componentes del sistema.

- `Slides.jsx` — carrusel 1080×1350: Portada (negro), Problema (condensada), Método (LetterTiles), Caso (ColumnText), Cifras (Stat), Cierre (rojo + CTA).
- `Formats.jsx` — post cuadrado 1080×1080 (Dato, Nota) y banner de perfil 1584×396 (la zona izquierda queda libre para la foto de perfil).
- `index.html` — visor: cambia formato arriba, navega con ← → o la tira inferior.

No hay un producto previo que recrear: estas piezas son la primera aplicación del look & feel de referencia (boards de Cannes Lions). Las imágenes grises son placeholders para fotos reales.
