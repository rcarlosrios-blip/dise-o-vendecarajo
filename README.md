# Carajo Vende — Sistema de diseño

Sistema visual de **Carajo Vende**, la marca personal de Roberto Ríos, para posteos en redes (LinkedIn, Instagram): carruseles, posts cuadrados y banner de perfil.

La skill vive en [`.claude/skills/posteos-redes-pics/`](.claude/skills/posteos-redes-pics/) — empieza por `SKILL.md` y `readme.md`.

## Usarla

**Claude Code:** al abrir este repo, la skill se carga sola. Invócala con `/posteos-redes-pics`.

**Claude.ai (chat):** empaqueta la carpeta y súbela en Settings → Capabilities → Skills.

```bash
cd .claude/skills && zip -r posteos-redes-pics.zip posteos-redes-pics
```

## Actualizarla

Edita los archivos de la carpeta, haz commit y vuelve a subir el ZIP a claude.ai para que el chat use la versión nueva.
